# Archived BeamNG migration

BeamNG is no longer a production provider. This directory retains its provider,
installation checks, telemetry mapper, sensor configuration, dashboard client,
tests and migration notes as historical source.

The complete runnable state is on `codex/beamng-migration-archive`, commit
`7a6a777`. The copies here are reference material; historical imports should be
run on that branch, not against today's CARLA backend.

The Three.js archive can still import the archived browser transport for
historical compatibility. Production imports none of these modules.

No BeamNG executable or license key is bundled. The previous live simulator
milestones were blocked and were not claimed as passed.
