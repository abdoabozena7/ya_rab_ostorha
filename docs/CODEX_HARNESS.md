# Superseded: native Copilot harness

The previous Codex delegation architecture was rejected. Its bridge, separate
authentication dependency and Codex-only hook configuration have been removed.
Historical sources and evidence are retained locally for audit, not used as
current acceptance.

Use the [native Copilot harness guide](COPILOT_NATIVE_HARNESS.md). The selected
Copilot model remains in charge; helpers provide deterministic planning,
execution, verification and recovery without another model client.
